# AstrBot 经济系统插件

一个功能完整的 AstrBot 经济系统插件，支持打卡签到、虚拟炒股、商店交易，所有功能均可通过 AI 工具调用。

## 功能特性

### 核心功能
- **打卡签到** - 每日签到获取金币，支持连续签到奖励
- **金币系统** - 金币余额管理、转账功能
- **商店系统** - 商品买卖、管理员上架/下架商品
- **股票系统** - 虚拟炒股，支持自动涨跌、供需影响、涨跌幅限制
- **排行榜** - 金币排行榜、股票资产排行榜、总资产排行榜

### AI 工具
所有功能均可通过 AI 工具调用，支持自然语言交互：
- 查询用户余额
- 执行签到操作
- 商店查询/购买/上架/下架
- 股票查询/买入/卖出/查看持仓
- 排行榜查询
- 管理员调整用户金币

## 安装方法

1. 将 `astrbot_plugin_economy` 文件夹放入 AstrBot 的 `data/plugins/` 目录
2. 重启 AstrBot 或在 WebUI 中重载插件

## AI 工具列表

插件提供以下 AI 工具，可被 LLM 自动调用：

### 1. balance_operation（金币操作）
```json
{
  "action": "query|add|remove|set",
  "user_id": "用户ID",
  "amount": 100
}
```

### 2. do_sign（执行签到）
```json
{
  "user_id": "用户ID"
}
```

### 3. shop_operation（商店操作）
```json
{
  "action": "query|buy|add|remove",
  "user_id": "用户ID",
  "item_id": 1,
  "name": "商品名称",
  "price": 100,
  "description": "商品描述"
}
```

### 4. stock_operation（股票操作）
```json
{
  "action": "query|buy|sell|portfolio|add|remove",
  "user_id": "用户ID",
  "stock_id": "BTC",
  "shares": 10,
  "name": "比特币",
  "price": 50000
}
```

### 5. query_ranking（排行榜查询）
```json
{
  "ranking_type": "coins|stock|total",
  "limit": 10
}
```

## 配置说明

在 AstrBot WebUI 的插件管理中可以配置以下选项：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `initial_coins` | int | 100 | 新用户初始金币 |
| `sign_reward` | int | 10 | 每日签到奖励 |
| `sign_bonus` | int | 5 | 连续签到奖励（每7天） |
| `stock_update_interval` | int | 30 | 股价更新间隔（分钟） |
| `max_price_change` | int | 10 | 最大涨跌幅（%） |
| `admin_ids` | list | [] | 管理员用户ID列表 |
| `enable_stock_system` | bool | true | 启用股票系统 |
| `enable_shop_system` | bool | true | 启用商店系统 |

## 股票系统说明

### 股价波动机制
- **自动波动** - 每隔固定时间自动更新股价
- **供需影响** - 用户买入推高价格，卖出压低价格
- **涨跌幅限制** - 单次波动不超过 ±10%（可配置）
- **趋势系统** - 股票有上涨/下跌/稳定三种趋势

### 波动算法
- 基础随机波动 (-5% ~ +5%)
- 趋势加成（上涨+2%，下跌-2%）
- 均值回归倾向（偏离基准越远，回归倾向越强）

## 注意事项

1. 管理员需要在配置中设置 `admin_ids` 字段
2. 股票系统需要一定时间才会产生价格波动
3. 所有数据存储在 SQLite 数据库中，位于 `data/plugin_data/astrbot_plugin_economy/`
4. 插件支持热重载，修改代码后可在 WebUI 中重载
